# 🛡️ КиберЩит: Беларусь

Обучающая игра о кибербезопасности: регистрация и вход, 22 сюжетных дела, побочные истории, допросы, тренажёр звонков мошенников, кабинет, звания, медали, рейтинг, режим для школ и PDF-сертификат.

Next.js 16 · React 19 · PostgreSQL (Drizzle ORM) · Tailwind CSS

> ⚠️ Это **не** обычный HTML-сайт: «Go Live» и GitHub Pages не подойдут — игре нужен сервер (Node.js) и база данных для аккаунтов.

---

## 🖥 Запуск на компьютере

Нужно: **Node.js 20+** (https://nodejs.org) и база данных — **Docker Desktop** (https://www.docker.com) или PostgreSQL.

**Windows:** дважды кликните `start-game.bat`.

**Вручную:**
```bash
npm install
docker compose up -d        # база данных
cp .env.example .env        # Windows: copy .env.example .env
npm run dev
```
Откройте **http://localhost:3000**. Таблицы в базе создаются автоматически.

> Без базы данных игра тоже запускается, но только в гостевом режиме (без регистрации, рейтинга и классов).

## 🌍 Публикация в интернете (бесплатно): GitHub + Vercel + Neon

1. **GitHub.** Загрузите эту папку в новый репозиторий (например, через GitHub Desktop → *Add local repository* → *Publish repository*). Проверьте, что загрузились `src`, `public` и `package.json`.
2. **База данных.** Зарегистрируйтесь на **https://neon.tech** → *Create project* → скопируйте строку подключения `postgresql://...`.
3. **Хостинг.** Зайдите на **https://vercel.com** через GitHub → *Add New → Project* → выберите репозиторий → откройте *Environment Variables* и добавьте:

   | Переменная | Значение |
   |---|---|
   | `DATABASE_URL` | строка подключения из Neon |
   | `CONTACT_EMAIL` | ваш e-mail для вопросов о данных |
   | `OPERATOR_NAME` | ваше имя или название школы |

4. Нажмите **Deploy**. Через 1–2 минуты игра будет доступна по адресу `https://ваш-проект.vercel.app`.

Таблицы создадутся сами при первом запросе. После каждого изменения в GitHub Vercel обновляет сайт автоматически.

## ❓ Частые проблемы

| Проблема | Решение |
|---|---|
| Список файлов вместо игры | Вы открыли через «Go Live». Используйте `npm run dev` и http://localhost:3000 |
| 404 на GitHub Pages | GitHub Pages не запускает сервер. Публикуйте через Vercel (см. выше) |
| «База данных недоступна» при регистрации | Не запущена база: `docker compose up -d`, проверьте `DATABASE_URL` |
| `'npm' не является командой` | Установите Node.js и перезапустите VS Code |
| Порт 3000 занят | `npm run dev -- -p 3001` |
